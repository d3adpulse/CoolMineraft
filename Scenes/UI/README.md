# Scenes/UI

HUD собирается кодом в `Scripts/UI/Hud.cs` (CanvasLayer + Label + прицел),
поэтому отдельная сцена здесь не нужна: меньше рассинхрона между `.tscn`
и скриптом.

Если понадобится редактировать HUD визуально — создайте `Hud.tscn`
с корнем `CanvasLayer`, повесьте на него `Hud.cs` и создайте дочерние
`Label`/`Control` с именами, которые использует скрипт.
